01 / OVERVIEW

About the Project

The Face Recognition Attendance System is developed using Python and OpenCV. It detects and recognizes registered faces and records attendance automatically. The main objective is to reduce manual work, save time and improve attendance management.

02 / FEATURES

What the System Offers

01

Face Detection

Detects human faces through camera input using computer vision.

02

Face Registration

Registers individuals and collects face data for recognition.

03

Face Recognition

Recognizes registered individuals using the LBPH method.

04

Attendance Recording

Automatically records attendance after successful recognition.

05

Student Management

Helps organize student information and attendance records.
