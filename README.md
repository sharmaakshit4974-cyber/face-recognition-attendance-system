# 👤 Face Recognition Attendance System

## 🚀 Project Overview

The Face Recognition Attendance System is a computer vision-based application developed using Python and OpenCV. The system identifies registered individuals through facial recognition and automatically records their attendance.

The main purpose of this project is to reduce manual attendance work, save time and improve the accuracy of attendance management.

## 🎯 Objectives

- Automate the attendance recording process.
- Identify registered individuals using facial recognition.
- Reduce manual work and human errors.
- Maintain attendance records digitally.
- Provide an efficient attendance management system.

## ✨ Key Features

- Face Detection
- Face Registration
- Face Recognition
- Automated Attendance Recording
- Student Data Management
- Attendance Records in CSV Format
- Graphical User Interface

## 🛠️ Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier
- LBPH Face Recognizer
- Tkinter
- CSV File Handling

## ⚙️ Installation and Setup

### Step 1: Install Python
Download and install Python on your computer.

### Step 2: Install Required Libraries

Open the terminal and run:

```bash
pip install opencv-contrib-python numpy
```

### Step 3: Open the Project

Open the project folder in Visual Studio Code.

### Step 4: Run the Application

Run the main Python file:

```bash
python main.py
```

Make sure you run the command from the directory containing `main.py`.

## 🔄 Working Methodology

1. Register a person's face.
2. Capture facial images using a camera.
3. Train the face recognition model.
4. Detect and recognize registered faces.
5. Record attendance automatically.
6. Save attendance records in CSV format.
